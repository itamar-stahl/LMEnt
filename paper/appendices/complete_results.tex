\section{Complete Held-Out Results by Concept}
\label{app:full-results}

Tables~\ref{tab:appendix-rome-results}--\ref{tab:appendix-ai-results} report the
complete held-out results separately for each concept. In each table, Panel~A
gives likelihood-ranked option accuracy on the target, neighboring, and shared
SciQ test sets. The harmonic score is reported
for the twin and five erasure conditions. It is always normalized against the
full model; the twin's value therefore provides the reference outcome of
concept exclusion. The full model has zero target efficacy and hence
$H_{\mathrm{test}}=0$ by construction. Panel~B reports the mean and standard deviation
across the same 50 test questions in each group. Here,
$\Delta\mathrm{NLL}_{M-T}$ compares it with the concept-excluded twin, and
$\mathrm{KL}(T\,\|\,M)$ uses the twin as the reference distribution. Panel~C
isolates the twin--full comparison that establishes how much concept exclusion
changed the model before any erasure method is considered. Thus, smaller
absolute NLL differences and lower KL indicate closer agreement with the
corresponding reference. All entries come from checkpoints selected using the
rule in Appendix~\ref{app:checkpoint-selection}; selection-set measurements are not
included in these tables.
